This translation previously documented a multi-host product. This Dreamliner
fork is **Codex-only**.

```bash
uv tool install graphifyy
graphify install                 # default platform: Codex
graphify install --platform codex
```

Then in Codex:

```
$graphify .
```

Always-on wiring uses `AGENTS.md` via `graphify install` / `graphify codex install`.

For the current Codex-only instructions, use the [English README](../../README.md).
